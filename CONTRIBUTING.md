# Panduan Kontribusi

Catur taktis dengan perisai kristal, penyerapan jiwa bidak, petak medan elemen, mantra Aether, dan kabut perang. React 19, Vite, dan Tailwind CSS.

## Menjalankan

```bash
npm install
npm run dev    # http://localhost:3000
```

## Sebelum mengirim perubahan

- `npm run lint` harus bersih.
- Setiap aturan mekanik baru harus dijelaskan singkat di README.
- Jangan commit `.env`, kunci API, atau hasil build.

## Alur kontribusi

1. `git checkout -b fix/nama-singkat`
2. Commit dengan pesan yang jelas.
3. Buka pull request ke `main`, jelaskan **apa** dan **kenapa**.

Untuk masalah keamanan, ikuti `SECURITY.md`, jangan buka issue publik.
